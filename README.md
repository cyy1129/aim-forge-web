# AIM FORGE · 瞄准训练场

无构建步骤的浏览器 FPS 瞄准训练器，支持八种玩法、可活动的人形机器人和玩家走位。使用 Canvas 绘制透视场景，人物由带深度和光照的几何部件构成，渲染和射线判定共用头、躯干、四肢模型。

## 本地运行

在项目目录运行：

    python3 -m http.server 8765 --directory dist

然后打开 http://localhost:8765。ES 模块需通过 HTTP 服务加载。

## 玩法

| 模式 | 行为 |
| --- | --- |
| 精准点射 | 3 个静止目标，一击击倒 |
| 平滑跟枪 | 按住左键，持续追踪平滑运动目标 |
| 多目标点射 | 6 个静止目标，连续定位 |
| 移动靶点射 | 4 个横向移动目标，把握点射时机 |
| 急变向跟枪 | 目标随机急停变向并改变距离 |
| 跳跃靶挑战 | 3 个弹跳目标，练习垂直瞄准 |
| 击杀切换 | 4 个移动目标，按住连射，打空血条再切换 |
| 移动对枪 | 3 个急变向目标，配合玩家 WASD 走位训练 |

八种玩法均支持人形机器人和经典球体。对枪是移动射击训练，机器人不会反击。

## 操作与计分

- WASD 前后左右移动，方向随镜头旋转；Shift 加速。界面也提供可按住的方向按钮。
- 左键点射；在跟枪、击杀切换和移动对枪中按住左键。
- 鼠标锁定模式支持自由转向；不支持锁定的浏览器自动使用普通光标，右键拖动可转向。
- 玩家活动范围 X 为 −12～12，Z 为 −6～8，避免穿过训练墙或走进目标。
- Space 暂停 / 继续；Esc 释放鼠标并暂停；R 重新开始。切换后台自动暂停并清除移动按键状态。
- 点射命中或连射击倒得 100 分；人形头部终结得 150 分。
- 连射每秒 10 发。目标生命为 100；头部伤害 85、躯干 34、四肢 25，球体伤害 34。爆头命中数按命中头部的子弹累计。
- 跟枪每秒有效追踪得 100 分；追踪率为有效追踪时间 / 整轮时间。
- 平均击倒间隔为开始 / 上一次击倒至本次击倒的平均时间。
- 可选 30、60、120 秒、三种难度和水平 FOV。灵敏度是本站倍率，不是其他游戏的灵敏度换算。
- 设置和最近 20 次完整训练保存在 localStorage，界面显示最近 5 次。旧版成绩可继续读取。

## 验证

    node tests/core.test.mjs

覆盖移动镜头后的射线一致性、人物命中部位、头身伤害、击倒补靶、计分、不同帧率的连射频率、跟枪、玩家移动边界，以及全部 16 种玩法与模型组合。

主要文件：dist/core.mjs 为几何和训练逻辑，dist/render.mjs 为透视场景与人物渲染，dist/app.mjs 为输入、状态与记录。静态部署配置位于 .openai/hosting.json。

本项目与 KovaaK’s 无隶属关系。界面字体通过 Google Fonts 加载，离线时使用系统字体。

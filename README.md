# AIM FORGE · 瞄准训练场

一个无构建步骤、无后端依赖的浏览器瞄准训练器。Canvas 绘制透视场景，使用射线与球体求交判断命中。

## 使用

在项目目录运行 `python3 -m http.server 8765 --directory dist`，然后打开 http://localhost:8765。ES 模块需通过 HTTP 服务加载。

- 精准点射：同时出现 3 个目标，命中后补充；每次命中 100 分。
- 平滑跟枪：按住左键追踪移动球体；每秒有效追踪 100 分，追踪率为有效追踪时间 / 整轮时间。
- 目标切换：同时出现 6 个目标，练习连续转移；每次命中 100 分。
- 可选 30、60、120 秒和三种难度。平均反应为开始 / 上一次命中至本次命中的平均间隔。
- FPS 鼠标锁定模式支持本站灵敏度倍率与水平 FOV。它不是其他游戏的灵敏度换算器；转向范围限定在训练墙附近。
- 浏览器拒绝鼠标锁定时自动切换到普通光标训练；触屏也使用此模式。
- Space 暂停 / 继续；Esc 释放鼠标并暂停；R 开始新一轮；切换后台自动暂停。
- 设置和最近 20 次完整训练保存在 localStorage，界面显示最近 5 次成绩。清除浏览器站点数据会删除记录。

本项目是独立原型，与 KovaaK’s 无隶属关系。界面字体通过 Google Fonts 加载，离线时使用系统字体。

## 文件

- `dist/index.html`：训练界面。
- `dist/style.css`：响应式样式。
- `dist/core.mjs`：透视、射线、目标生成与训练计分。
- `dist/app.mjs`：输入、渲染、状态控制与本地记录。
- `.openai/hosting.json`：Sites 静态部署配置。

# AIM FORGE · 瞄准训练场

无需框架或后端的浏览器 FPS 瞄准训练器，支持十四种单靶玩法、带关节步态的人形假人和玩家走位。使用 Canvas 绘制透视场景，人物使用圆润椭球部件、连续明暗和可活动的膝肘关节，渲染轮廓与射线判定共用头部、躯干、四肢几何。

## 公网试玩与部署

GitHub Pages 地址：https://cyy1129.github.io/aim-forge-web/

访客无需登录。页面不加载外部字体、脚本或接口，所有运行资源都随站点部署。仓库的 dist 目录可直接交给任何静态托管服务。

修改源文件后，先运行 `node scripts/prepare-assets.mjs`。脚本为样式、入口和依赖模块生成内容版本文件，并更新首页引用，避免发布时旧缓存造成按钮样式与页面结构错配。生成的文件一并提交并部署，保留可读源文件供编辑和测试。

GitHub Pages 发布源为 gh-pages 分支根目录，保留 .nojekyll 文件。更新 dist 后，可使用 git subtree split 导出 dist 目录，再将结果推送到发布分支。GitHub Pages 会重新发布。

## 本地运行

在项目目录运行：

    node scripts/prepare-assets.mjs
    python3 -m http.server 8765 --directory dist

然后打开 http://localhost:8765。ES 模块需通过 HTTP 服务加载。

## 玩法

| 模式 | 行为 |
| --- | --- |
| 精准点射 | 一个静止目标，命中后刷新下一个 |
| 平滑跟枪 | 按住左键，持续追踪平滑运动目标 |
| 单靶切换 | 一次一个静止目标，命中后随机出现下一个；未命中则保留当前目标 |
| 移动靶点射 | 一个横向移动目标，命中后刷新下一个 |
| 急变向跟枪 | 目标随机急停变向并改变距离 |
| 跳跃靶挑战 | 一个弹跳目标，命中后刷新下一个 |
| 击杀切换 | 一个移动目标，按住连射，打空血条后刷新下一个 |
| 移动对枪 | 一个急变向目标，配合玩家 WASD 走位，击倒后刷新下一个 |
| 闪现反应 | 单靶短暂出现，快速命中得额外奖励；超时记漏靶并扣分 |
| 微甩精修 | 更小的目标在上一个目标附近刷新，训练细微修正 |
| 急停点射 | WASD 移动后必须停稳 0.10 秒，移动中射击无效 |
| 掩体探头 | A/D 侧移，从真实挡弹掩体两侧瞄准交替出现的单靶 |
| 爆头限定 | 自动使用人形假人，只有头部命中有效 |
| 缩靶挑战 | 目标的可见轮廓和命中范围同步缩小，消失前必须命中 |

全部玩法每次最多显示一个目标。普通点射命中、连射击倒后刷新下一个；跟枪持续追踪同一个移动目标；闪现和缩靶超时后记录漏靶，间隔 0.30 秒出下一靶。爆头限定强制使用人形靶，其他模式支持经典球体和人形假人。对枪是移动射击训练，目标不会反击。急停和掩体模式自动开启走位，离开这些模式会恢复原本保存的模型和移动偏好。

默认使用经典球体，点击“重置”也会恢复球体。旧版保存的模型选择首次升级时会重置一次，之后手动选择的模型会继续保存。

## 操作与计分

- WASD 前后左右移动，方向随镜头旋转；Shift 加速。界面也提供可按住的方向按钮。
- 左键点射；在跟枪、击杀切换和移动对枪中按住左键。
- 鼠标锁定模式支持自由转向；不支持锁定的浏览器自动使用普通光标，右键拖动可转向。
- 玩家活动范围 X 为 −12～12，Z 为 −6～8，避免穿过训练墙或走进目标。
- Space 暂停 / 继续；Esc 释放鼠标并暂停；R 重新开始。切换后台自动暂停并清除移动按键状态。
- 本轮未结束时，模式区会提示切换限制。点击其他模式会暂停并说明原因；可继续本轮，或点击“结束并切换”。训练区顶部和暂停面板均提供醒目的结束按钮；点击结束会退出全屏并返回模式设置，提前结束不会保存成绩。
- 训练区右上角的“全屏训练”按钮或 F 键切换全屏；全屏中可通过退出按钮或 Esc 返回。不支持原生全屏时，自动进入铺满浏览器窗口的专注模式。
- 普通点射命中或连射击倒得 100 分；人形头部终结得 150 分。闪现反应根据命中速度额外奖励 0～100 分；闪现和缩靶超时扣 25 分，最低为 0 分。
- 连射每秒 10 发。目标生命为 100；头部伤害 85、躯干 34、四肢 25，球体伤害 34。爆头命中数按命中头部的子弹累计。
- 跟枪每秒有效追踪得 100 分；追踪率为有效追踪时间 / 整轮时间。计时模式的命中率也计入漏靶；失误数包含未命中、规则判定无效和漏靶。
- 两种跟枪模式中，准星进入球体的实际命中范围会立即变蓝，离开后恢复绿色；变色不需要按住左键，计分仍需按住。
- 平均击倒间隔为开始 / 上一次击倒至本次击倒的平均时间。
- 可选 30、60、120 秒、三种难度。通用配置使用本站灵敏度倍率；三角洲配置使用实测转身距离匹配。
- 设置和最近 20 次完整训练保存在 localStorage，界面显示最近 5 次。旧版成绩可继续读取。

## 三角洲输入配置（第一阶段）

选择“三角洲行动 · PC 键鼠”，直接填写游戏内鼠标灵敏度与 FOV，并保持相同的硬件 DPI。无需量厘米或执行采样校准。

- 灵敏度采用社区换算工具 [PSA Method](https://www.psamethod.cn/sensitivity/delta-force/) 的 0.022 度/计数参考值。它不是官方确认的完整游戏输入模型，尚未覆盖屏幕距离系数、FOV 与灵敏度联动、ADS 和各倍率瞄具，因此界面明确标为“参考匹配”。
- “手感微调”默认 1×，偏快调低、偏慢调高，可直接输入小数，或点击慢一点/快一点按 5% 调整。水平与垂直倍率分别生效；通用配置继续使用本站倍率。
- FOV 按 16:9 基准水平角输入，转换为训练画布当前水平角，保持不同画面比例的垂直视野一致。可选自动、16:9、16:10、4:3、21:9，固定比例会留黑边。FOV 定义参考 [Mouse Sensitivity 作者实测](https://www.mouse-sensitivity.com/forums/topic/9303-delta-force-%E4%B8%89%E8%A7%92%E6%B4%B2%E8%A1%8C%E5%8A%A8/page/4/)，需按当前游戏版本复核。
- 优先请求原始鼠标输入，不可用时回退普通鼠标锁定；锁定失败会显示普通光标提示，不会假称输入一致。网页不修改硬件 DPI。
- 全屏画布按所选比例居中，模式、退出按钮和成绩采用悬浮 HUD，不再被工具栏压缩。
- 配置只保存在当前浏览器，旧版设置可迁移；重置恢复通用训练与经典球体。已移除手工距离测量及校准流程。

本阶段提供腰射参考配置与视野适配，尚未实现 ADS、武器后坐力或三角洲移动物理。

## 验证

    node tests/core.test.mjs
    node tests/round-ui.test.mjs
    node tests/advanced.test.mjs
    node tests/input-profile.test.mjs

覆盖移动镜头后的射线一致性、人物命中部位、头身伤害、击倒补靶、计分、不同帧率的连射频率、跟枪、玩家移动边界，以及全部十四种玩法与球体 / 人形设置（爆头限定会强制人形）。

训练流程测试执行实际应用事件处理，检查锁定提示、继续训练、结束并切换、提前结束不保存成绩及自然结束解锁。该测试使用受控 DOM 和动画时钟，不代替浏览器视觉检查。

输入测试另覆盖精确灵敏度驱动镜头、微调倍率、旧校准数据不再生效、五种比例的 FOV 与射线一致性，以及配置保存、重置和训练中锁定。浏览器预览检查了配置切换、全屏悬浮布局与鼠标锁定失败提示。

主要文件：dist/input-profile.mjs 为输入和视野换算，dist/core.mjs 为几何和训练逻辑，dist/render.mjs 为透视场景与人物渲染，dist/app.mjs 为输入、状态与记录。静态部署配置位于 .openai/hosting.json。

人物建模思路参考 [KovaaK’s 角色配置文档](https://wiki.kovaaks.com/home/KovaaK%27s/ScenarioCreation/CharacterProfiles)，本项目使用自行生成的圆润训练假人和关节动画，无需额外下载模型。

本项目与 KovaaK’s 无隶属关系。界面使用系统字体，无需访问 Google Fonts。
